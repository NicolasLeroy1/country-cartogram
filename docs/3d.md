# Experimental 3D maps

Start with the [2D workflow](../README.md). 3D is an optional way to inspect a
second quantity; it is harder to read reliably than area alone.

For quantities `A` and `B`, the encoding is:

```text
footprint area = area_scale × A
height        = height_scale × B / A
volume        = area_scale × height_scale × B
```

Supply extensive quantities in explicit units. With population and total GDP,
height represents GDP per person. Every country shares the same two scales.

A small footprint with a large `B / A` ratio becomes a tall, thin column. It can
look like a mesh artifact even when the geometry is correct. Height tells you
the ratio, so a tall country does not necessarily have a large second total.
Transparency cannot make these columns easy to compare. Use **Top view** to
read footprints and **Country values** to compare the actual quantities.

The exporter keeps heights linear and uncapped so volume retains its meaning.
Reducing `height_scale` makes all columns shorter together; extreme ratios still
dominate. The numerical audits check geometry, not whether the chart is readable.

## Generate or update

```bash
country-cartogram examples/population-gdp.csv \
  --value-column population --volume-column gdp_usd \
  --config examples/population-gdp.json --config-3d examples/population-gdp.3d.json \
  --out output/population-gdp
```

Once a layout exists, update the second quantity without running physics:

```bash
country-cartogram-3d output/population-gdp.layout.json new_values.csv \
  --area-column population --volume-column gdp_usd \
  --config examples/population-gdp.3d.json --out output/new-heights
```

The first quantities and country coverage must match the saved layout. Colors
come from its companion audit or `--style config.json`. Extrusion uses the
prepared polygons saved by the solver; it does not simplify them again.
See [shape approximation](algorithm.md) for the preprocessing error budget.

## Appearance and scale

The optional 3D configuration accepts:

```json
{
  "title": "Population and GDP",
  "area_label": "Population (people)",
  "height_label": "GDP per person (USD)",
  "volume_label": "GDP (USD)",
  "source_note": "Source and year",
  "height_scale": null,
  "opacity": 0.4,
  "surface_noise": 0.2,
  "noise_frequency": 3
}
```

| Setting | Meaning |
| --- | --- |
| `height_scale` | One positive multiplier for all ratios; `null` fits the maximum height to 25% of the map span |
| `opacity` | Per-surface opacity, 0.1–1; also adjustable in the viewer |
| `surface_noise` | Perlin normal strength, 0–0.5 |
| `noise_frequency` | Broad surface waves, 0.25–12 |

Materials are matte and translucent. The Perlin field changes normals without
moving vertices or changing volumes. The top view uses opaque footprints.
Weighted blended transparency avoids whole-country sorting flips where
floating-point render targets are available; other devices use alpha blending.
Overlapping color mixing is approximate. At 100% opacity, the viewer uses normal
opaque depth rendering.

Use an explicit `height_scale` and a fixed area scale to compare separate maps.
Timelines choose a common height scale across every frame automatically.
Heights remain linear; there is no clipping or individual normalization.

## Inputs and checks

- `A > 0, B = 0`: a flat footprint with zero volume.
- `A = 0, B = 0`: omitted and recorded in the audit.
- `A = 0, B > 0`: rejected.
- Missing, negative, nonfinite, or duplicate quantities: rejected.

Constrained triangulation retains concavities, holes, and islands. Positive-height
meshes have roofs, floors, and outward walls. Checks independently measure roof
area, edge closure, and signed mesh volume. Float32 display buffers are checked
against a 2% area/volume error budget. Input quantities are retained separately
from the display buffers; hover values and the table show five significant digits.

| Output | Content |
| --- | --- |
| `.3d.html` | Offline Three.js viewer and country table |
| `.3d.png` | Optional opaque Matplotlib preview (`--preview-3d` or standalone `--preview`) |
| `.3d.metrics.csv` | Quantities, heights, volumes, mesh counts, errors |
| `.3d.audit.json` | Scales, hashes, display errors, versions, timings |

The HTML needs WebGL2 and `DecompressionStream`. Use **Save image** to capture
its current translucent view. `--html-js cdn` loads the pinned engine externally;
the default bundles it for offline use. Python needs no separate 3D dependency.

## Benchmark

```bash
python scripts/benchmark_3d.py output/population-gdp.layout.json examples/population-gdp.csv \
  --area-column population --volume-column gdp_usd \
  --config examples/population-gdp.3d.json --out output/population-gdp --repeats 3
```

This writes `.benchmark.json` with loading, meshing, audit, and HTML timings.
It excludes physics, PNG generation, interpreter startup, and browser rendering.
Use `--html-js cdn` to measure the smaller external-engine export.
